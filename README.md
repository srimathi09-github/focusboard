# FocusBoard - Task Management Dashboard

FocusBoard is a responsive personal task management dashboard built using React and Vite.

## Features

- Create, edit and delete tasks
- Delete confirmation dialog
- Task status management
- Low, Medium and High priorities
- Search tasks by title and description
- Filter tasks by status and priority
- Dynamic dashboard statistics
- Focus Notes carousel with three slides
- LocalStorage persistence
- Responsive desktop, tablet and mobile layouts

## Technologies

- React
- Vite
- JavaScript
- CSS
- Lucide React
- Browser LocalStorage

## Installation

Clone the repository:

\`\`\`bash
git clone YOUR_GITHUB_REPOSITORY_URL
\`\`\`

Navigate to the project:

\`\`\`bash
cd focusboard
\`\`\`

Install dependencies:

\`\`\`bash
npm install
\`\`\`

Start the development server:

\`\`\`bash
npm run dev
\`\`\`

## Persistence

Tasks are stored in browser LocalStorage and remain available after refreshing the page.

## Responsive Design

The dashboard supports desktop, tablet and mobile screen sizes.
